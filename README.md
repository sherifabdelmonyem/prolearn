
# ProLearn

> AI Voice-Native Learning Platform for Blind and Visually Impaired Students

## Vision

ProLearn is an intelligent educational platform designed specifically for blind and visually impaired learners.

The platform is powered by a Super Multi-Agent System coordinated by an AI Router that distributes tasks among specialized AI agents.

## Technology Stack

- Flutter
- Dart
- Python
- FastAPI
- PostgreSQL
- Redis
- Qdrant
- Docker
- Power BI
